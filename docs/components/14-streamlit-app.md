# Component 14 — `app/streamlit_app.py` (interactive UI)

**Weeks:** 5 (shell) → 9 (complete) · **Status:** stub shell · **Depends on:** everything upstream

## Function

The public face: configure a backtest, see the charts, talk to the AI, watch Research mode
iterate — plus the safety states (passcode gate, cached fallback, remaining budget) rendered
honestly. Engine-agnostic: it drives the same interfaces/tools as the agent.

## Requirements satisfied

- **FR-10** — config panel, Plotly charts, AI chat, Research mode, engine selector, one-click
  scenarios. **DL-2** — what the live URL serves. **SF-2** — budget display + graceful cached
  fallback (never an error page). **SF-4** — passcode gate for live AI. **AR-1** — uses registries
  only.

## Layout

Sidebar = configuration (tickers multiselect from UNIVERSE, date range within train+val for
interactive runs, strategy + params driven by `PARAM_WHITELIST`, cost_bps, engine selector
Python / R / KNIME*). Main area = tabs:
**Backtest** · **Portfolio** · **AI Chat** · **Research mode** · **Methodology**.
(*R in the selector = the R analytics view of the same run — tearsheet image + R-vs-Python
metric comparison table; it is the polyglot story made visible. KNIME appears only if the
stretch engine ships.)

## Interface (integral functions)

```python
def main() -> None                                   # page config + sidebar + tab dispatch

def sidebar_config() -> dict                         # validated run config from the controls
    # {"tickers", "start", "end", "strategy", "params", "cost_bps", "engine"}

@st.cache_data
def run_pipeline(cfg: dict) -> BacktestResult        # load (cached parquet) -> signals -> engine
    # st.cache_data keyed on cfg -> repeat clicks are free; this is also why interactive
    # (non-AI) backtests need no budget gate — they cost CPU only.

def plot_equity(result) -> plotly Figure             # equity curve vs equal-weight benchmark
def plot_drawdown(result) -> plotly Figure           # underwater chart
def plot_frontier(frontier_df, weights) -> Figure    # frontier scatter + max-Sharpe marker
def render_metrics(metrics: dict) -> None            # st.metric row: sharpe, cagr, max_dd, ...

def render_chat() -> None                            # AI Chat tab -> nl_interface.handle();
                                                     # renders explanation + the run's charts
def render_research() -> None                        # Research tab -> agent.run_research();
                                                     # iteration timeline; val vs holdout side by side
def render_scenarios() -> None                       # one-click buttons -> load_scenario()

def load_scenario(name: str) -> dict                 # precomputed results from scenarios/<name>/
    # (interchange-format parquet files, committed). Serves three duties: instant demo,
    # SF-2 budget-exhausted fallback, SF-4 ungated-visitor content.

def gate_live_ai() -> bool                           # True if DEMO_PASSCODE matched this session
    # (st.session_state); shows remaining budget via budget.remaining(). Ungated or
    # budget-exhausted -> scenarios with a plain-language banner, never an error.
```

## Design notes

- Every AI entry point checks `gate_live_ai()` **and** lets `nl_interface`/`agent` enforce their
  own gates — the UI gate is UX, the module gates are the security boundary.
- Prebuilt scenarios (~3: "momentum on tech", "mean-reversion long-short", "combined portfolio")
  are generated by a small script and committed, so a fresh clone demos with zero network/API.
