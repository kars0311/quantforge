## Plan (one workflow, two jobs)

```yaml
on: [push, pull_request]            # main branch + PRs
jobs:
  python:                           # every push — must stay fast (< ~2 min)
    - setup-python 3.12 with pip cache
    - pip install -r requirements.txt
    - ruff check .
    - pytest                        # offline by design (see tests doc); R tests auto-skip
  r-cross-check:                    # the heavy polyglot job — nightly schedule + manual trigger,
    - setup R + arrow/PerformanceAnalytics/PortfolioAnalytics (cached)   # not per-push
    - pytest tests/test_r_cross_check.py
```

## Done when

Badge green on main; a deliberately broken push goes red on both ruff and pytest failures.
